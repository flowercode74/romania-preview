# رومانیا — بازطراحی قلمرو و رابط

بازی استراتژی فارسی با چیدمان راست به چپ و هدر منابع چپ به راست، قابل اجرا با Live Server.
این نسخه فعلاً محلی و تک‌نفره است؛ اتصال حساب و چندنفره هنوز پیاده‌سازی نشده‌اند.

## نصب بستهٔ تغییرات

1. از پروژهٔ فعلی یک نسخهٔ پشتیبان بگیرید.
2. محتوای پوشهٔ `Romania` در ZIP را روی پوشهٔ پروژهٔ فعلی کپی کنید و جایگزینی فایل‌های هم‌نام را بپذیرید.
3. پوشهٔ `assets` قبلی را حذف نکنید. بسته شامل تصاویر WebP ساختمان و دیوار، آیکون‌های اصلی منو و فایل‌های اجرایی اصلاح‌شده است.
4. روی `index.html` در VS Code راست‌کلیک و **Open with Live Server** را انتخاب کنید. سپس `Ctrl+F5` بزنید.

**خروجی‌ها از قبل ساخته شده‌اند؛ برای نصب این بسته اجرای build ضروری نیست.**
ذخیرهٔ قبلی در همان مرورگر و نشانی قبلی حفظ می‌شود. چیدمان‌های قدیمی یک بار به چیدمان جدید منتقل می‌شوند؛ سطح ساختمان‌ها، منابع و صف‌ها حفظ می‌شوند.

## تغییرات این نسخه

- تم مینیمال زغالی، زیتونی و برنز؛ بازی RTL و فقط هدر منابع LTR.
- آیکون‌های تصویری اصلی منوی پایین و آیکون مأموریت در عنوان پنل.
- تصویر ساختمان به عرض سطح کاشی‌های اشغال‌شده می‌رسد؛ سقف طبیعی از سطح پایه بالاتر می‌رود، بدون کشیدگی یا بریدن تصویر.
- نگه‌داشتن ساختمان به مدت حدود نیم‌ثانیه، حالت جابه‌جایی را فعال می‌کند. آن را بکشید و با ✓ تأیید کنید. فرود و خاک در محل جدید پخش می‌شود. قلعه و دیوار ثابت‌اند؛ جابه‌جایی پس از آموزش فعال است.
- نوشته‌های شفاف بالای ساختمان، بدون قاب؛ نمایش هنگام حرکت دوربین و محوشدن تدریجی پس از چند ثانیه. برچسب دیوار بالاتر قرار دارد.
- کارت مأموریت فعلی کوتاه‌تر و شیشه‌ای است؛ هالهٔ مصنوعی پرچم مزیت حذف شده است.
- عملیات ساختمان با دکمه‌های گردِ سبک نقشه: عملیات تخصصی از راست، سپس ارتقا و اطلاعات.
- آموزش و مأموریت‌ها با تصویر ساختمان، توضیح، پیشرفت، تصاویر پاداش، دریافت و «برو به ماموریت». راهنما دوربین را روی ساختمان می‌برد و عمل مربوط را مشخص می‌کند؛ لمس جای دیگر علامت را پاک می‌کند.
- خاک پیوسته درون دیوار و بافت چمن و پوشش گیاهی در بیرون؛ تصاویر ساختمان‌های نسخهٔ قبل حفظ شده‌اند.

## توسعه

پس از تغییر کد در `src`، در ترمینال پوشهٔ حاوی `package.json` اجرا کنید:

```powershell
npm.cmd run build
npm.cmd run check
npm.cmd test
```

برای این دستورات به نصب بستهٔ اضافی نیاز نیست. Node.js نسخهٔ ۱۸ یا جدیدتر لازم است.

## اعتبارسنجی و محدودیت

۹ مجموعهٔ آزمون، بررسی ارجاع دارایی‌ها و کنترل نسبت ابعاد تصاویر و اندازهٔ سطح اشغال موفق بودند. رندر مستقیم تابع قلمرو با تصاویر نهایی در سه اندازه بررسی شد.

**آزمون تعاملی در مرورگر انجام نشد:** مرورگر محیط اجرا دسترسی به سرور محلی و فایل پروژه را مسدود کرد. تصویر `docs/territory-preview.webp` رندر مستقیم Canvas بازی است، نه اسکرین‌شات مرورگر. آزمون لمسی روی گوشی واقعی هم انجام نشده است.

پرومپت‌ها و فهرست تصویرها در `docs/ART_PROMPTS.md` و گزارش نسخهٔ جدید در `docs/refinement-validation.json` قرار دارند.
