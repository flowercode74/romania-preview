# بررسی نسخهٔ مرتب‌شده

- ساخت خروجی JavaScript و CSS و بررسی نحوی JavaScript.
- بررسی توازن آکولاد CSS، یکتایی شناسه‌های HTML و وجود ۶۶ ارجاع ثابت و خانواده‌های تولیدشدهٔ تصاویر/فایل‌های اجرا.
- شش مجموعهٔ اصلی: economy، island، logic، military، npc و runtime.
- مجموعهٔ regression: ادامه و بازیابی ذخیره، مهاجرت JSON خراب، نسخهٔ نامعتبر ذخیره، مقدار نامعتبر مخزن، مسیرهای ناامن تصویر، تصاویر Inventory و کش/خطای تصویر.
- مجموعهٔ HTTP: صفحهٔ ورود، فایل‌های اجرای CSS/JS، آیتم، GIF، MIME WebP، فایل مفقود و دسترسی‌نداشتن به فایل‌های داخلی از سرور توسعه.
- مقایسهٔ ابعاد و تمام پیکسل‌های RGBA هر ۶۲ تصویر تبدیل‌شده با فایل اصلی؛ بدون تغییر پیکسل. GIF و JPG حفظ شده‌اند.
- بازتولید جدول بالانس از مقادیر اجرایی و بررسی سلامت آرشیو ZIP.

دستورهای اصلی:

```sh
npm run build
npm run check
npm test
node tests/economy.cjs --docs
```

آزمون‌های gameplay با DOM و Canvas شبیه‌سازی‌شده اجرا می‌شوند. آزمون HTTP واقعی است. رندر تصویری، لمس واقعی و اندازه‌گیری FPS انجام نشده‌اند: Playwright موجود است، اما فایل اجرایی Chromium نصب نیست.

## به‌روزرسانی قلمرو

نه مجموعهٔ آزمون شامل آزمون تازهٔ `territory.cjs` اجرا شدند: محدودهٔ چهارکاشی، برخورد با دیوار و دروازه، نسبت صحیح تصویر، حد دوربین و زوم در شش اندازهٔ صفحه، انتقال جایگاه‌های قدیمی بدون حذف پیشرفت و ثابت‌ماندن نقطهٔ درگ.

تابع واقعی `drawWorld` با تصاویر موجود و Canvas بومی در دو اندازهٔ ۷۲۰×۶۵۰ و ۳۹۰×۶۲۰ رندر و تصاویر بررسی شدند. این بررسی شامل رندر DOM/CSS و لمس مرورگر واقعی نیست.
