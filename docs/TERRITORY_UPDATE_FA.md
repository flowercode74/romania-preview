# قلمرو جمع‌وجور و مقیاس کاشی‌ها

## نصب

۱. محتویات پوشهٔ `Romania` این ZIP را روی پوشهٔ پروژهٔ قبلی جایگزین کنید.
۲. پوشهٔ `assets` موجود خود را حفظ کنید؛ این بسته هیچ فایلی از آن پوشه ندارد.
۳. داخل پوشهٔ پروژه اجرا کنید:

```sh
npm run build
npm run check
npm test
npm start
```

ساخت خروجی ضروری است: فایل‌های اجرایی تازه در مسیرهای قبلی `assets/js/game.js` و `assets/css/game.css` ساخته می‌شوند. نام و محتوای تصاویر عوض نشده‌اند. ساختار `src`، `scripts`، `tests` و `docs` حفظ شده است.

## تغییرات

- تصویر دیوار با اندازهٔ ۴۴۰×۳۸۰ در مختصات جهان رسم می‌شود؛ نسبت آن به تصویر اصلی نزدیک است و کشیدگی شدید قبلی برطرف شده است.
- محوطهٔ ساخت، چندضلعی منطبق با فضای داخل همین دیوار است؛ محدودهٔ مستطیلی و بسیار کشیدهٔ قبلی حذف شده است.
- قلعه، سربازخانه، مرکز تحقیقات، سفارت و بیمارستان چهار کاشی متصل، در دو ردیف جابه‌جا، اشغال می‌کنند. تعمیم الگوی چهارکاشی تصویر مرکز تحقیقات به این پنج ساختمان، تصمیم طراحی این نسخه است.
- اردوگاه، مخفیگاه، مزرعه، چوب‌بری و معادن سنگ و آهن یک کاشی اشغال می‌کنند.
- عرض کاشی برابر `sqrt(3) × hexSize` است. عرض مجاز تصویر تک‌کاشی ۹۲٪ این مقدار و عرض مجاز چهارکاشی ۹۲٪ عرض محدودهٔ چهار کاشی است. شکل اصلی تصویر حفظ می‌شود؛ بنابراین ساختمان کوتاه یا پهن برای پرکردن تمام ارتفاع کاشی کشیده نمی‌شود.
- حاشیهٔ شفاف تصاویر فعلی هنگام رسم کنار گذاشته می‌شود؛ خود فایل تصاویر و شفافیت آن‌ها ویرایش نشده‌اند. اگر تصویر جایگزین با اندازهٔ متفاوت باشد، رسم به ابعاد کامل همان تصویر برمی‌گردد.
- مرکز تصویر، برچسب‌ها، نقطهٔ انتخاب و درگ، با مرکز کاشی‌های اشغال‌شده هماهنگ شده‌اند. نمایش ساختمان‌های جلویی پس از ساختمان‌های عقب انجام می‌شود.
- کف داخلی سنگی و خاکی روشن، خطوط شبکه قابل تشخیص و بیرون دیوار سبز است. پیش‌نمایش سبز/قرمز جایگذاری زیر ساختمان رسم می‌شود.
- شبکهٔ زمین از ۴۱×۴۱ به ۱۵×۱۵ کاهش یافته است؛ زمین‌های دوری که برای قلمرو لازم نبودند حذف شده‌اند. نقشهٔ جهان تغییری نکرده است.

## دوربین و زوم

حد دید دوربین، مستطیل دیوار به اضافهٔ ۱۶ واحد حاشیه در هر طرف است. حداقل زوم از عرض و ارتفاع واقعی محیط محاسبه می‌شود تا تمام لبه‌های صفحه در همین محدوده بمانند. حداکثر زوم ۲٫۴ برابر حداقل زوم همان صفحه است؛ نمای اولیه ۱٫۰۳ برابر حداقل زوم است. حرکت، چرخ ماوس، زوم دو انگشتی، آموزش و تغییر اندازهٔ صفحه همین محدودیت را رعایت می‌کنند.

در صفحه‌های بسیار کشیده، برای جلوگیری از نمایش زمین زیاد بیرون دیوار، بخشی از دیوار در نمای اولیه بیرون قاب خواهد بود؛ بازیکن می‌تواند با حرکت دوربین آن بخش را ببیند. نمایش کامل دیوار در هر نسبت صفحه همراه با حاشیهٔ خارجی بسیار کم، بدون تغییر نسبت تصویر یا اندازهٔ محیط نمایش امکان‌پذیر نیست.

## ذخیره‌های موجود

کلید و نسخهٔ ذخیره، منابع، سطح ساختمان‌ها، موجودی آیتم‌ها و صف‌ها حفظ می‌شوند. جایگاه‌های قدیمی که با محوطهٔ جدید سازگار نباشند به چیدمان اولیهٔ جدید برمی‌گردند. جایگاه‌های معتبر همین نسخه پس از ذخیره و ورود مجدد حفظ می‌شوند. این انتقال با شروع بازی تازه یا حذف حساب انجام نمی‌شود.

## اعتبارسنجی

آزمون‌های قبلی موفق‌اند. آزمون تازهٔ قلمرو، برخورد، نسبت تصویر، شش اندازهٔ صفحه، حداقل/حداکثر زوم، انتقال ذخیره و درگ بدون جهش را بررسی می‌کند. رندر واقعی Canvas با تصاویر فعلی در دو اندازه بررسی شده است. آزمون تعاملی مرورگر یا گوشی واقعی انجام نشده است.
